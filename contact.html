Quick Answers

Is TagsAI completely free?
Yes! TagsAI is free to use. You only need your own Anthropic API key, which has a free tier for new users.
How many tags does it generate?
TagsAI generates exactly 20 relevant YouTube tags per generation. You can regenerate as many times as you like to get different tag sets.
Does TagsAI store my video data?
No. Your video title or description is sent to the AI API to generate tags and is not stored on our servers. Read our Privacy Policy for full details.
Why am I getting a network error?
This is usually a CORS issue when calling the AI API directly from a browser. You need a backend proxy. See the README.md file included with the project for setup instructions.
Can I use the generated tags commercially?
Yes. Tags generated by TagsAI are yours to use freely on your YouTube channel and any other platform.
